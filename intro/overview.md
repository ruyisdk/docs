# 1.1 产品简介

RuyiSDK是中国科学院软件研究所主导开发的开源套件，旨在为RISC-V开发者提供一套完整、全栈的开发工具链，涵盖编译、调试、模拟等全流程环节，并兼容主流RISC-V开发板。该套件以 `ruyi` 包管理器为核心，打通从开发、测试到部署的关键环节，向开发者提供一站式服务。

## 诞生背景：为什么 RISC-V 开发需要专属的“工具集”？

近年来，RISC-V 架构凭借其开放与灵活的特性迎来了爆发式增长，各类开发板与处理器层出不穷。然而，硬件的繁荣并没有直接转化为开发者的体验红利。

对于开发者而言，RISC-V 开发往往意味着繁琐的环境拼凑：你需要去不同芯片厂商的官网寻找特定版本的交叉编译器，去开源社区翻找对应的 QEMU 模拟器配置，手动解决 Sysroot 依赖冲突，还要面对各种烧录工具和调试插件的兼容性问题。这种“找工具-配环境-解冲突”的割裂体验，极大地拉高了 RISC-V 的上手门槛。

RuyiSDK 的诞生正是为了终结这种碎片化现状。它不是一个单一功能的软件，而是一个专为 RISC-V 场景量身定制的集成开发环境——将散落各处的开发工具标准化、集中化，让开发者不再为环境配置耗费精力。

## 核心能力：一站式打通全流程

RuyiSDK 覆盖了从写代码到部署上线的各个关键环节。通过核心的 `ruyi` 包管理器及各 IDE 插件，开发者可以获得以下开箱即用的能力：

* **编译环节**：提供 GCC 与 LLVM 等主流 RISC-V 交叉编译工具链的一键安装，通过内置的虚拟环境机制，支持多环境并存与切换，灵活指定和自定义 Sysroot，轻松实现不同目标板构建环境的隔离，告别繁琐的环境变量配置与依赖冲突。
* **调试环节**：提供开箱即用的远程调试支持，配合 IDE 插件，让在 x86 主机上调试 RISC-V 目标板程序像调试本地程序一样自然。
* **模拟环节**：深度集成 QEMU 等模拟器，即使手头没有实体硬件，开发者也能在本地轻松构建出一个 RISC-V 虚拟运行环境，进行功能验证与测试。
* **部署环节**：打通主流 RISC-V 开发板的镜像下载与烧录流程，只需几条简单命令，即可完成系统的刷写与更新。

## 开源协作与生态共建

RuyiSDK 采用开源模式，项目代码、工具配置均在全球开源社区托管，欢迎全球开发者参与协作与共建。

作为面向 RISC-V 生态的基础工具集，RuyiSDK 通过与芯片厂商及操作系统社区的深度协作，正将原本碎片化的 RISC-V 开发资源，逐步转化为触手可及的基础设施。

**广泛的硬件兼容**

在硬件生态侧，RuyiSDK 致力于打破不同硬件平台之间的壁垒，广泛支持市面上的主流 RISC-V 芯片与开发板，并积极与各硬件厂商开展合作，旨在通过提供统一、易用的开发工具，大幅降低 RISC-V 的开发门槛，吸引更多开发者加入，共同促进 RISC-V 软硬件生态的繁荣。

**广泛的发行版适配**

在软件生态侧，RuyiSDK 也在积极与各大 Linux 发行版社区开展协作，推动 RISC-V 开发工具的深度融合。

- **广泛可用**：RuyiSDK 首先确保广泛的可用性，针对多种主流发行版进行适配和支持。 当前 RuyiSDK 已经完成了 Arch Linux、Gentoo、Fedora、Debian、openRuyi、Ubuntu、openEuler、deepin、openKylin、OpenCloudOS 等的适配，提供多种便捷的部署方式（如下载独立二进制包、使用 pip 安装、配置系统扩展软件源等），确保不同生态的开发者都能无障碍接入。
- **融入官方生态**：在广泛可用的基础上，RuyiSDK 持续推动自身融入各发行版的官方生态。目前，Arch Linux、Gentoo、Fedora、Debian、openRuyi 等社区已将 `ruyi` 纳入官方软件源仓库，开发者可直接通过系统原生包管理器安装使用。从项目适配到被发行版官方接纳，正是开源协作的生动体现。我们还将继续努力，争取让 RuyiSDK 进入更多发行版的官方生态，乃至成为系统级工具，将便利的开发环境推向更广阔的社区。

## 哪些场景适合使用 RuyiSDK？

面对 RISC-V 开发环境的碎片化问题，不同角色的开发者会在不同场景下遇到各自的痛点。以下场景中，RuyiSDK 可以为你提供切实的帮助：

* **RISC-V 零基础入门与快速尝鲜**
  当你刚接触 RISC-V，只想赶紧写个“Hello World”跑起来，却卡在交叉编译器下载、环境变量配置的泥潭里。RuyiSDK 提供开箱即用的工具链与内置模拟器支持，无需实体开发板，一条命令即可在 x86 电脑上完成 RISC-V 程序的编译与运行，将环境搭建时间从数小时缩短至几分钟。
* **多开发板适配与多目标环境隔离**
  当你需要同时为多款 RISC-V 开发板开发软件，不同板子的 Sysroot 依赖和工具链版本往往互相冲突。RuyiSDK 的虚拟环境机制允许你为不同项目创建相互隔离的构建环境，灵活指定自定义 Sysroot，告别繁琐且易错的全局环境变量切换。
* **底层系统软件构建与工具链频繁切换**
  当你在开发操作系统内核或底层固件，需要在不同版本的 GCC/LLVM 之间频繁切换以验证兼容性。RuyiSDK 将各类主流工具链标准化收纳，支持一键安装与无缝切换，让你免去了手动编译工具链或处理复杂依赖的痛苦。
* **团队协同与 CI/CD 自动化构建**
  当团队开发经常遭遇“我这能跑，你那报错”的环境差异问题，或者 CI 流水线难以复现本地构建结果。通过 RuyiSDK，团队可以精确声明和锁定工具链及依赖版本，确保所有成员与自动化环境使用完全一致的构建基础，实现真正的可复现构建。
* **无实体硬件依赖的模拟运行与测试**
  当你手头暂缺 RISC-V 实体开发板，却需要在本地运行或测试 RISC-V 程序。手动配置 QEMU 启动参数、寻找匹配的内核与固件往往极其繁琐。RuyiSDK 集成了主流模拟器并预设了已支持开发板的运行配置，只需简单指令即可一键拉起虚拟运行环境，让你无需深究模拟器细节，即可专注于代码逻辑的验证。
